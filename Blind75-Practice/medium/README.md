# Medium difficulty — scaffold

This folder mirrors the NeetCode-style **pattern** taxonomy used in [`easy/`](../easy/). Topic subfolders now contain **Java/** directories with empty filename scaffolds only.

**Intended use:** NeetCode 150 / 250 **medium** problems (and similar), grouped by pattern.

**Current scope:** Java only. No `Python/` folders or `tests/` trees are needed here yet.

**Next steps:** Pick a problem from [NeetCode](https://neetcode.io/practice), open the matching empty file under the topic's `Java/` folder, and implement it when you're ready.
