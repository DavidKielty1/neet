# Blind75 Study Structure

## Overview
This directory is organized following the **pattern-first approach** recommended in the Blind75 study guide. Each pattern folder contains subfolders for different data structures where that pattern is commonly applied.

## Directory Structure

```
Blind75/
├── easy/
│   ├── 01-two-pointers/
│   │   ├── arrays/          # Two Sum, Container With Most Water, 3Sum
│   │   └── strings/         # Valid Palindrome, Reverse String
│   ├── 02-sliding-window/
│   │   ├── arrays/          # Maximum Subarray, Minimum Size Subarray
│   │   └── strings/         # Longest Substring Without Repeating Characters
│   ├── 03-binary-search/
│   │   └── arrays/          # Binary Search, Search Insert Position
│   ├── 04-hash-maps-sets/
│   │   ├── arrays/          # Contains Duplicate, Intersection of Arrays
│   │   └── strings/         # Valid Anagram, Group Anagrams
│   ├── 05-dfs/
│   │   ├── trees/           # Maximum Depth, Validate BST
│   │   └── graphs/          # Number of Islands, Clone Graph
│   ├── 06-bfs/
│   │   ├── trees/           # Level Order Traversal, Min Depth

│   └── 07-dynamic-programming/

└── hard/
```

## How to Use This Structure

### 1. **Pattern-First Learning**
- Start with the pattern folder (e.g., `01-two-pointers/`)
- Understand the core concept and when to use it
- Practice with both arrays and strings variations

### 2. **Data Structure Context**
- Each data structure subfolder shows how the pattern applies
- Helps understand pattern variations and edge cases
- Builds intuition for pattern recognition

### 3. **Progressive Difficulty**
- Start with easy problems in each pattern
- Move to medium/hard as you master the pattern
- Cross-reference with your study guide timeline

### 4. **File Naming Convention**
- Use descriptive names: `two-sum.ts`, `valid-palindrome.py`
- Include multiple language implementations if desired
- Add solution notes in comments

## Benefits of This Structure

1. **Pattern Recognition**: Learn to identify which pattern to use
2. **Interview Preparation**: Practice explaining pattern choices
3. **Efficient Review**: Easy to find similar problems for review
4. **Progressive Learning**: Build complexity within each pattern
5. **Cross-Pattern Learning**: See how patterns combine in complex problems
